## 동시성 (concurrency)

- 한 번에 여러 작업을 동시에 다루는 것을 의미 == **스위칭**을 하면서 작업을 동시에 다룸
- 논리적 개념 ➡️ 멀티 스레딩과 싱글 스레드 두 곳 모두에서 사용되기도 함
- 싱글 코어 뿐만 아니라 멀티 코어에서도 각각의 코어가 동시성을 사용할 수 있음

## 병렬성 (parallelism)

- 한 번에 여러 작업을 병렬적으로 처리하는 것을 의미
- 물리적 개념 ➡️ 멀티 코어 또는 멀티 스레딩에서만 병렬성 프로그래밍 가능
- 동시성과 공존 가능
- 파이썬에서는 멀티 스레딩으로 병렬성 구현 불가능
