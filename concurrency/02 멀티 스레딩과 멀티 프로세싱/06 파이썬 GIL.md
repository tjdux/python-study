## 멀티 스레딩의 단점

- 스레드끼리 자원 공유 ➡️ 하나의 자원을 동시에 여러 스레드가 가져가려는 상황에서 충돌 발생 ➡️ 하나의 스레드가 다른 스레드에 의해 차단될 수 있음
- 파이썬 GIL은 이런 문제점을 방지
  <br/>

## GIL (Global Interpreter Lock)

- 한 번에 한 개의 스레드만 유지하는 락 (병렬성 불가)
- 한 스레드가 다른 스레드를 차단해서 제어를 얻는 것을 막음 (멀티 스레딩의 위험으로부터 보호)
- ➡️ 파이썬에서는 스레드로 병렬성 연산 수행 불가
- 파이썬 멀티 스레딩은 동시성을 사용하여 io bound 코드에서 유용하게 사용할 수 있지만, cpu bound 코드에서는 GIL에 의해 원하는 결과를 얻을 수 없음
  <br/>
