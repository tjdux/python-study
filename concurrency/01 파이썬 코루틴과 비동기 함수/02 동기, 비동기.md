## 동기 (Sync)

- 코드가 반드시 작성된 순서 그대로 실행

```python
import time

def task(name, delay):
    print(f"{name} 시작")
    time.sleep(delay)
    print(f"{name} 완료")

task("작업1", 2)
task("작업2", 2)

# 4초 소요
```

<br/>
## 비동기 (Async)
- 코드가 반드시 작성된 순서 그대로 실행되는 것은 아님

```python
import time
import asyncio

async def task(name, delay):
    print(f"{name} 시작")
    await asyncio.sleep(delay)
    print(f"{name} 완료")

async def main():
    await asyncio.gather(
        task("작업1", 2),
        task("작업2", 2)
    )

asyncio.run(main())

# 약 2초 소요
```
